# Hanzo Search

Lightning-fast full-text search engine.

## Overview

Hanzo Search is a blazingly fast, typo-tolerant search engine designed for instant search experiences. Deliver sub-50ms search results with advanced ranking, filtering, and faceting for your AI-powered applications.

## Features

- **Instant Search**: Sub-50ms response times out of the box
- **Typo Tolerance**: Intelligent handling of misspellings
- **Faceted Search**: Filter and refine results dynamically
- **Custom Ranking**: Flexible relevancy tuning
- **Multi-language**: Support for 30+ languages
- **RESTful API**: Simple JSON-based API

## Quick Start

```bash
docker run -p 7700:7700 hanzo/search
```
